# Claude-Konto anlegen

<p class="updated">Stand: <time datetime="2026-11">November 2026</time></p>

Claude ist die KI von Anthropic. Mit **Claude Code**, dem Werkzeug dazu, bauen wir im Workshop deine App. Später baust du damit selbst weiter.

Rechne mit 10 Minuten.

> **Das kostenlose Konto reicht nicht.** Claude Code braucht einen bezahlten Plan: Pro, Max, Ultra, Team oder Enterprise. Alternativ geht ein Konto in der Claude Console, dort zahlst du nach Verbrauch. Welcher Plan zu dir passt, klären wir im Kickoff.

## 1. Registrieren

1. Öffne [claude.ai](https://claude.ai/).
2. Melde dich mit deiner E-Mail-Adresse an. Claude schickt dir einen Link oder Code per E-Mail, ein Passwort gibt es nicht.
3. Trag deinen Namen ein und bestätige die Bedingungen.

## 2. Plan buchen

1. Klicke links unten auf deinen Namen und öffne die Einstellungen.
2. Wähle unter **Abrechnung** bzw. **Upgrade** den Plan, den wir im Kickoff besprochen haben.
3. Hinterlege eine Zahlungsmethode.

Arbeitet ihr zu mehreren damit, ist der Plan **Team** sinnvoll. Dann verwaltet ihr Zugänge und Rechnungen an einer Stelle.

## 3. Claude Code anmelden

Hast du Claude Code schon installiert (siehe [Vorbereitung]({{base}}vorbereitung/)), teste gleich die Anmeldung:

```bash
claude
```

Beim ersten Start öffnet sich der Browser. Melde dich dort mit deinem Claude-Konto an und bestätige den Zugriff. Danach siehst du im Terminal die Eingabe von Claude Code. Mit `/exit` beendest du es wieder.
