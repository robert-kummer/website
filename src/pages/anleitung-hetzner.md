# Hetzner-Account anlegen

<p class="updated">Stand: <time datetime="2026-11">November 2026</time></p>

Hetzner ist ein deutscher Hoster mit Rechenzentren in Deutschland und Finnland. Dort läuft später deine WebApp, auf einem Server, den du selbst bezahlst und der dir gehört.

Diesen Account brauchst du nur für eine WebApp. Für eine Mac-App brauchst du keinen Server. Nutzt du schon einen anderen Hoster in der <abbr title="Europäischen Union">EU</abbr>, schreib mir. Oft geht es auch dort.

> **Wichtig: Fang früh an.** Hetzner prüft neue Kunden. Manchmal verlangt Hetzner eine Kopie deines Ausweises oder eine Vorauszahlung per Kreditkarte, bevor du einen Server anlegen kannst. Das kann etwas dauern. Leg den Account deshalb gleich nach dem Kickoff an.

Rechne mit 15 Minuten, plus Wartezeit für die Prüfung.

## 1. Registrieren

1. Öffne [hetzner.com](https://www.hetzner.com/) und klicke auf **Registrieren** bzw. **Login** und dort auf Registrieren.
2. Gib deine E-Mail-Adresse ein und bestätige sie über den Link in der E-Mail.
3. Trag deine Daten ein: Name oder Firma, Anschrift und, falls vorhanden, die Umsatzsteuer-ID.

Zwei Tipps von Hetzner selbst, damit die Prüfung glatt läuft:

- Nutze möglichst eine Firmenadresse statt einer kostenlosen Adresse wie Gmail oder GMX.
- Schalte ein <abbr title="Virtual Private Network, verschlüsselter Tunnel ins Internet">VPN</abbr> während der Registrierung aus.

## 2. Zahlungsmethode hinterlegen

Wähle eine Zahlungsmethode, zum Beispiel Kreditkarte oder SEPA-Lastschrift. Bezahlt wird erst, wenn ein Server läuft. Kleine Server kosten wenige Euro im Monat. Die aktuellen Preise stehen auf [hetzner.com/cloud](https://www.hetzner.com/cloud).

## 3. Prüfung abschließen, falls verlangt

Fordert Hetzner eine Verifizierung an, hast du in der Regel zwei Wege:

- **Ausweis:** Du lädst eine Kopie deines Personalausweises oder Reisepasses hoch.
- **Vorauszahlung:** Du zahlst einen kleinen Betrag per Kreditkarte im Voraus. Er wird mit späteren Rechnungen verrechnet.

Hängt die Prüfung länger, hilft der Hetzner-Support. Sag mir in dem Fall Bescheid, damit wir den Workshop-Termin nicht gefährden.

## 4. Zwei-Faktor-Anmeldung einschalten

Wer deinen Hetzner-Account übernimmt, kann deine Server löschen. Schalte deshalb in deinem Hetzner-Konto in den Sicherheitseinstellungen die Zwei-Faktor-Anmeldung ein. Du brauchst dafür eine Authenticator-App auf dem Handy. Speichere die Wiederherstellungscodes im Passwortmanager.

## 5. Cloud-Projekt anlegen

1. Öffne aus deinem Hetzner-Konto die **Cloud Console**.
2. Lege ein neues Projekt an. Als Namen nimmst du deine Firma oder den Namen der App.

Einen Server legst du noch nicht an. Das machen wir zusammen im Workshop.

## Fertig?

- [ ] Die Zwei-Faktor-Anmeldung ist eingeschaltet.
- [ ] In der Cloud Console gibt es ein leeres Projekt.
