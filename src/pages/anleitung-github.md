# GitHub-Account anlegen

<p class="updated">Stand: <time datetime="2026-11">November 2026</time></p>

Auf GitHub liegt der Quellcode deiner App. Jede Änderung wird dort gespeichert, und von dort wird die App automatisch auf deinen Server ausgerollt. Der Account gehört dir, nicht mir.

Rechne mit 10 bis 15 Minuten. Der kostenlose Plan reicht.

## 1. Registrieren

1. Öffne [github.com/signup](https://github.com/signup).
2. Gib deine E-Mail-Adresse ein. Nimm eine Adresse, auf die du dauerhaft Zugriff hast. Für ein Unternehmen ist eine Firmenadresse besser als eine private.
3. Wähle ein Passwort. Am besten lässt du es von einem Passwortmanager erzeugen.
4. Wähle einen Benutzernamen. Er ist öffentlich sichtbar und wird Teil von Adressen wie `github.com/dein-name`.
5. Löse die Prüfaufgabe und gib den Code ein, den GitHub dir per E-Mail schickt.

Kommt die Meldung, dass die E-Mail-Adresse nicht genutzt werden kann, hilft oft ein anderer Browser oder ein privates Fenster.

## 2. Zwei-Faktor-Anmeldung einschalten

GitHub verlangt von allen, die Code ablegen, eine Anmeldung mit zweitem Faktor. Richte sie gleich ein, dann fragt GitHub nicht mitten im Workshop danach.

1. Klicke oben rechts auf dein Profilbild und dann auf **Settings**.
2. Öffne links **Password and authentication**.
3. Klicke auf **Enable two-factor authentication**.
4. Wähle eine Authenticator-App auf deinem Handy, zum Beispiel die App deines Passwortmanagers, und scanne den QR-Code.
5. Speichere die **Recovery Codes**. Mit ihnen kommst du wieder in deinen Account, wenn das Handy weg ist. Lege sie in den Passwortmanager oder drucke sie aus.

Zusätzlich kannst du dort einen **Passkey** anlegen. Dann meldest du dich per Fingerabdruck oder Gesichtserkennung an.

## 3. Für Unternehmen: Organisation anlegen

Arbeiten mehrere Leute an der App, oder soll sie nicht an einer Person hängen, lege zusätzlich eine Organisation an. Dein eigener Account bleibt, die Organisation ist der gemeinsame Ort für den Code.

1. Klicke oben rechts auf das Plus-Zeichen und dann auf **New organization**.
2. Wähle den kostenlosen Plan **Free**.
3. Gib als Namen deine Firma an und als Kontakt eine Firmenadresse.

Bist du allein selbstständig, kannst du diesen Schritt überspringen.

## Fertig?

- [ ] Ich kann mich bei GitHub anmelden.
- [ ] Die Zwei-Faktor-Anmeldung ist eingeschaltet, die Recovery Codes sind gespeichert.
- [ ] Ich kenne meinen Benutzernamen (und den Namen der Organisation, falls angelegt).
